SURaj Surendran Portfolio Website

Files:
- index.html  : complete portfolio website
- suraj.png   : profile photo used by the website package

Publish options:
1. GitHub Pages: upload these files to a repository and enable Pages from the main branch.
2. Netlify: drag the folder contents into the deploy area.
3. Hostinger: upload index.html and suraj.png into public_html.

After publishing, use the public HTTPS URL in job applications.
